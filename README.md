Conslusão: Este trabalho demonstrou, na prática, como funciona o processo de criação e utilização de certificados digitais para comunicação segura. Foram realizadas etapas fundamentais como a geração de chave privada, criação da requisição de certificado (CSR), emissão de um certificado autoassinado e sua aplicação em um ambiente local.
Além disso, foi possível compreender a diferença entre os protocolos HTTP e HTTPS, evidenciada pelo erro ao tentar estabelecer uma conexão segura em um servidor que não estava configurado para SSL/TLS. Com isso, o trabalho reforça a importância da configuração correta do servidor para garantir a criptografia dos dados e a autenticidade das conexões.
Por fim, a atividade contribuiu para o entendimento prático de conceitos essenciais de segurança da informação, amplamente utilizados em aplicações web modernas.
